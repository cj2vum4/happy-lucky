新增一趟旅行
✎ 打開編輯器
📝 三步驟新增旅行
  1. 點上方按鈕進入編輯器，填好表單後下載 .json 檔
  2. 把這個 JSON 上傳到網站的 trips/ 資料夾
  3. 編輯 trips.json，在 trips 陣列加上這個檔名（不含副檔名）
📂 檔案架構
travel-site/
├─ index.html      ← 主網站（不要動）
├─ editor.html     ← 旅行編輯器
├─ trips.json      ← 旅行索引
└─ trips/
   ├─ nantou-2026.json
   └─ kyoto-2027.json ← 新增的旅行
🌐 部署到 GitHub Pages
  1. 到 github.com 註冊帳號
  2. 建立新 repository（名稱：travel-journal）
  3. 上傳這整個 travel-site 資料夾的所有檔案
  4. Settings → Pages → Source 選 main branch → Save
  5. 等 1-2 分鐘，得到 https://你的帳號.github.io/travel-journal
  6. 任何設備打開這個網址都能看到（含手機）
